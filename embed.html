Embed the 3D solar system on your website

You can put the interactive Mzu 3D Solar System on a class page, blog post, school LMS or Notion-style page for free. Copy the code below; no account or API key is needed.

Responsive iframe code

Paste this into any page that accepts HTML. It keeps a 16:9 shape and scales to the width of your column.

<div style="position:relative;width:100%;max-width:960px;aspect-ratio:16/9;">
  <iframe src="https://www.3dsolarsystem.net/" title="Interactive 3D Solar System"
    style="position:absolute;inset:0;width:100%;height:100%;border:0;border-radius:8px;"
    loading="lazy" allow="fullscreen; accelerometer; gyroscope" allowfullscreen></iframe>
</div>
<p style="font-size:14px;">Interactive solar system by
  <a href="https://www.3dsolarsystem.net/">Mzu 3D Solar System</a></p>

Please keep the credit line under the frame. It tells your readers where the explorer comes from and helps other teachers find it.

Just want a link?

If your platform strips iframes (many forums and some LMS editors do), a plain link works everywhere:

<a href="https://www.3dsolarsystem.net/">Explore the planets in 3D (Mzu 3D Solar System)</a>

Tips

  • Performance: the explorer uses WebGL. loading="lazy" makes it load only when a reader scrolls to it, so it does not slow down the rest of your page.
  • Phones and tablets: it works with touch (drag to rotate, pinch to zoom). On small screens, a link that opens it full screen is often more comfortable than a small frame.
  • Google Sites / Canvas / Moodle: use the editor’s “Embed” or “HTML” option and paste the code above.
  • Need the numbers too? Link to the planet data quick reference (NASA values) and the explorer guide.

Terms

Embedding is free for education and non-commercial pages. Do not frame it inside pages that claim the explorer as your own work, and do not remove the credit link. It is an artistic educational visualization, not a live ephemeris.
